# Contributing to AppsPerms

Terima kasih sudah tertarik kontribusi ke AppsPerms! 🎉

AppsPerms adalah AppOps manager open-source untuk Android via Shizuku — ringan, cepat, 100% offline.

## 🚀 Cara Kontribusi

### 1. Fork & Clone
```bash
git clone https://github.com/xykal/AppPerms.git
cd AppPerms
```

### 2. Buat Branch
```bash
git checkout -b feat/nama-fitur
# atau fix/nama-bug
```

### 3. Build & Test
```bash
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest
```

### 4. Commit dengan format Conventional Commits
```
feat: tambah fitur X
fix: perbaiki bug Y
docs: update README
style: format code
refactor: rapihin logic Z
```

### 5. Push & Pull Request
```bash
git push origin feat/nama-fitur
```
Buka PR di https://github.com/xykal/AppPerms/pulls

## 📋 Area yang Butuh Bantuan

- **UI/UX**: Material 3, animasi, dark theme, tablet layout
- **AppOps**: Research ROM OEM (One UI, HyperOS, ColorOS)
- **Shizuku**: Multi-profile, Secure Folder support
- **Terminal**: Preset commands, auto-complete
- **Tweaks**: Safe display tuning, animation scales
- **Web**: Landing page improvements, i18n
- **Docs**: Panduan Shizuku, troubleshooting, video
