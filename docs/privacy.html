Privacy

Effective 23 October 2026

Summary: the AppsPerms Android app does not request the Internet permission and has no advertising, analytics, or tracking SDK. Its website does not load analytics or tracking scripts.

Android app

  • App, package, AppOps, history, and settings data are processed on the device.
  • The app does not declare android.permission.INTERNET.
  • Shizuku or optional root access is used only for actions the user requests.
  • Privileged state is excluded from Android cloud backup and device transfer.
  • No telemetry, advertising identifier, analytics SDK, or remote account is used.

Website and downloads

  • The site is static and does not use Google Analytics or advertising scripts.
  • A local browser preference named site_lang remembers the selected language.
  • Cloudflare, GitHub, or the configured download host may process ordinary request data such as IP address, user agent, time, and requested file for delivery, abuse prevention, and security under their own policies.
  • Donation links open third-party services only after the user chooses them.

Verification and contact

Release filenames, sizes, and SHA-256 values are published in release.json. Submit sensitive security reports through the repository's private advisory form; use GitHub Issues only for non-sensitive privacy questions.
