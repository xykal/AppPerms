Apakah AppsPerms membutuhkan akses root? Does AppsPerms require root access?

Tidak harus. AppsPerms memanfaatkan Shizuku yang dapat dijalankan lewat Wireless Debugging / ADB pada Android 11+ tanpa PC dan tanpa root. Jika HP kamu sudah di-root, Shizuku juga bisa dijalankan via root. Not necessarily. AppsPerms uses Shizuku, which can run through Wireless Debugging / ADB on Android 11+ without a PC and without root. If your device is rooted, Shizuku can also start via root mode.

Mengapa AppsPerms membutuhkan akses Shizuku? Why does AppsPerms need Shizuku access?

Membaca dan mengubah status AppOps tersembunyi memerlukan hak akses sistem istimewa (UID 2000 shell). Shizuku menyediakan jembatan aman untuk eksekusi API sistem tersebut tanpa merusak integritas Android. Reading and modifying hidden AppOps requires privileged system permissions (UID 2000 shell). Shizuku provides a secure bridge to execute system APIs without compromising Android system integrity.

Apakah data saya aman dan tanpa koneksi internet? Is my data secure and completely offline?

AppsPerms memiliki nol (0) izin INTERNET di AndroidManifest.xml. Secara teknis, aplikasi ini mustahil mengirim data ke luar perangkat. Semua konfigurasi tersimpan lokal. AppsPerms declares zero (0) INTERNET permissions in AndroidManifest.xml. It is technically impossible for the app to send data off your device. All configurations remain strictly local.

Bagaimana cara verifikasi keaslian APK? How do I verify the authenticity of the APK?

Unduh APK dari link resmi dl.appsperms.xyverse.my.id, cocokkan nilai SHA-256 berkas dengan laporan audit pada bagian Keamanan di atas. Kamu juga bisa mengunggah berkas APK ke VirusTotal secara mandiri. Download the APK from the official dl.appsperms.xyverse.my.id link, then compare its SHA-256 hash with the Security audit table above. You can also independently submit the file to VirusTotal.

Bagaimana cara migrasi dari OverlayOps ke AppsPerms? How do I migrate from OverlayOps to AppsPerms?

Karena ID paket berubah dari app.overlayops menjadi app.appsperms, uninstall aplikasi lama terlebih dahulu, pasang versi AppsPerms baru, lalu setujui izin Shizuku sekali lagi. Konfigurasi dapat dipindahkan via fitur Backup & Restore. Because the package ID changed from app.overlayops to app.appsperms, uninstall the old app first, install the new AppsPerms build, and grant Shizuku permission once again. You can transfer settings via Backup & Restore.

Kenapa daftar aplikasi atau pencarian kosong? Why is the application list or search empty?

Pastikan Shizuku sedang aktif dan izin AppsPerms sudah disetujui. Coba ketuk tombol refresh atau bersihkan filter pencarian. Pada ROM OEM tertentu (One UI / HyperOS), pastikan tidak ada profil yang terisolasi tanpa izin. Ensure Shizuku is currently running and authorized. Tap the refresh button or clear search filters. On certain OEM skins (One UI / HyperOS), verify there are no restricted user profiles blocking app enumeration.
