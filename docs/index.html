FAQ

Pertanyaan yang sering ditanyakan.Frequently asked questions.

Apakah butuh root?Does it need root?

Tidak harus. Pakai Shizuku via Wireless Debugging di Android 11+ tanpa root & tanpa PC. Kalau HP sudah root, Shizuku bisa via root.Not necessarily. Use Shizuku via Wireless Debugging on Android 11+ without root & PC. If rooted, Shizuku can run via root.

Kenapa butuh Shizuku?Why need Shizuku?

AppOps tersembunyi butuh hak sistem UID 2000. Shizuku jadi jembatan aman tanpa rusak integritas Android.Hidden AppOps needs UID 2000 shell permission. Shizuku provides secure bridge without breaking Android integrity.

Apakah data aman & offline?Is data safe & offline?

0 izin INTERNET di Manifest. Secara teknis mustahil kirim data keluar. Semua konfigurasi lokal.Zero INTERNET permission in Manifest. Technically impossible to exfiltrate data. All config stays local.

Bagaimana verifikasi APK?How to verify APK?

Download dari /apk/AppsPerms-latest.apk, cocokkan SHA-256 dengan tabel Keamanan di atas, atau upload ke VirusTotal.Download from /apk/AppsPerms-latest.apk, match SHA-256 with Security table above, or upload to VirusTotal.

Kenapa download cepat?Why download is fast?

APK di-host langsung di Cloudflare edge (Singapore untuk Indonesia) dengan cache global, jadi download lebih cepat dan stabil.APK is hosted directly on Cloudflare edge with global cache, so downloads are faster and more stable.

Migrasi dari OverlayOps?Migrate from OverlayOps?

Uninstall OverlayOps lama (app.overlayops), pasang AppsPerms baru (app.appsperms), izinkan Shizuku lagi. Setting bisa via Backup & Restore.Uninstall old OverlayOps (app.overlayops), install new AppsPerms (app.appsperms), grant Shizuku again. Use Backup & Restore for settings.
